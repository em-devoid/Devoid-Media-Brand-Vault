# Website Assets

Drop brand imagery here, then wire it into the site (see comments in `css/styles.css`).

Recommended files:

| File | Used for | Notes |
|------|----------|-------|
| `hero-crest.png` | Hero moon/crest art | Transparent PNG, ~800px+ wide. See `.hero-art` in CSS. |
| `favicon.png` | Browser tab icon | Square, 512×512. Use the DM icon (girl + moon). |
| `og-image.jpg` | Link-share preview | 1200×630. What shows when the site is shared on socials. |
| `studio.jpg` | "The Studio" section | Landscape editorial/interior shot. |
| `portfolio/modeling.jpg` … | Portfolio cards | Portrait (3:4.4). One per category. |

Keep files web-optimized (JPG/WebP, compressed) so pages load fast — load speed affects both search ranking and how many visitors stay.
